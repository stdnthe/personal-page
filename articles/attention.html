LLM Basics

Attention 机制：模型如何决定该看哪里？

Attention 可以理解成一种“相关性搜索”：当前词提出问题，其他词拿出线索，模型再决定重点参考谁。

当模型处理一句话时，每个词都不应该孤立理解。比如“它很好用”里的“它”指什么，需要回到前文寻找线索。Attention 就是在做这种寻找。

Query 当前词提出的问题：我现在需要什么信息？
Key 其他词提供的索引：我这里有什么线索？
Value 真正被取走的信息：如果相关，就把内容贡献出来。

注意力权重是什么？

模型会比较 Query 和每个 Key 的匹配程度。越匹配，权重越高；权重越高，对应的 Value 就越会影响当前词的表示。

这不是人类显式写规则，而是在大量训练数据中学出来的统计关系。模型学会了哪些词之间经常互相解释、互相限定、互相补充。

为什么要多头注意力？

一句话里常常同时存在多种关系：主谓关系、指代关系、时间关系、因果关系。多头注意力让模型从多个角度观察同一句话。

一句话总结

Attention 让模型不只是按顺序读字，而是能动态判断“当前理解最需要参考哪里”。这也是 Transformer 能处理复杂上下文的关键。
